# OXI public columns

Approved public OXI blog index, thumbnail artwork and three concept-project stories.
The source is https://rss.blog.naver.com/oxi_studio.xml.
A scheduled GitHub Actions workflow checks the feed every 15 minutes (best effort).
It retains older articles when they roll off the RSS feed, preserves the last good data on failures, and generates matching 2:1 SVG covers locally without paid image services.
Only public article metadata and OXI-owned artwork are included.
